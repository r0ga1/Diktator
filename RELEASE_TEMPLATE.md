# Silbenlot VERSION · Beta

## Windows installieren

| Dein PC | Einmal herunterladen und ausführen |
| :--- | :--- |
| **Intel / AMD · x64** | **[Windows-Installer herunterladen →](https://github.com/r0ga1/silbenlot/releases/download/vVERSION/Silbenlot-Setup-x64.exe)** |
| **ARM · Snapdragon** | [Windows-Installer ARM64 herunterladen →](https://github.com/r0ga1/silbenlot/releases/download/vVERSION/Silbenlot-Setup-ARM64.exe) |

**Eine EXE genügt.** Modell und Laufzeit sind enthalten. Setup öffnen → Bedingungen
prüfen → Installieren → anschließend **Silbenlot im Startmenü** öffnen.
Windows 10/11, etwa 3 GB freier Speicher.

[Installation & Hilfe](https://github.com/r0ga1/silbenlot/blob/main/INSTALLATION.md)

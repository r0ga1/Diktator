# Silbenlot

Sprechen statt tippen. Lokales Diktieren für Windows mit Parakeet v3.
Kein Konto, keine Cloud-Spracherkennung.

## Herunterladen

| Dein Windows-PC | Installer · 0.12.0 Beta |
| :--- | :--- |
| **Intel / AMD** · die meisten PCs | **[Windows x64 herunterladen →](https://github.com/r0ga1/silbenlot/releases/download/v0.12.0/Silbenlot-Setup-x64.exe)** |
| **ARM** · z. B. Snapdragon | [Windows ARM64 herunterladen →](https://github.com/r0ga1/silbenlot/releases/download/v0.12.0/Silbenlot-Setup-ARM64.exe) |

1. **Eine passende EXE herunterladen und öffnen.** Kein ZIP entpacken.
2. Im Assistenten Bedingungen prüfen und **Installieren** wählen.
3. Danach **Silbenlot über das Startmenü öffnen**. Das Setup brauchst du nur zur Installation.

Windows 10/11 · etwa 3 GB freier Speicher · Modell und Laufzeit bereits enthalten.
Keine zusätzlichen Programme oder Modell-Downloads nötig.

## Lossprechen

Textfeld anklicken → **Strg + Alt + Leertaste** → sprechen → mit demselben Kürzel stoppen.
Der Text erscheint direkt im Textfeld. Kürzel, Texteingabe, Aufnahmefenster und Lautstärken sind einstellbar.

**Automatische Updates sind an.** Geprüfte Updates werden beim vollständigen Beenden installiert;
Schließen in den Infobereich reicht dafür nicht. Abschaltbar in **Einstellungen → Updates**.

> **Beta:** Windows kann wegen des noch unbekannten Herausgebers warnen.
> Die native Windows-Abnahme einschließlich des vollständigen automatischen Updateablaufs steht noch aus.
> [Prüfstand ansehen](https://github.com/r0ga1/silbenlot/releases/download/v0.12.0/Silbenlot-Pruefbericht.md).
